Frequently Asked Questions

How the referral codes on this site work.

How do I use a referral code from this site?

Open the provider's detail page, copy the referral code, then enter it during signup on the provider's website or app. Some providers (Neo Financial, Neobanc) use a referral link instead — clicking it applies the referral automatically.

Do the referral offers on this site change?

Yes. Providers change referral bonuses and terms regularly. Each page shows when it was last reviewed, but you should always confirm the reward and eligibility shown by the provider before applying.

Will I definitely receive the referral bonus?

Bonuses depend on meeting the provider's eligibility conditions (for example, a minimum deposit or completing verification). This site cannot guarantee a bonus — the provider's terms control.

Why do some entries use a link instead of a code?

Some providers run link-based referrals rather than codes. Neo Financial and Neobanc on this site use referral links; the rest use codes you enter at signup.

Do these referral codes expire?

The codes themselves are generally reusable, but the bonus attached to them can change or end at any time. If a code stops working, the detail page will be updated at the next review.

Is this site affiliated with the providers listed?

No. This is a personally maintained, independent site. The owner may receive a referral reward if you use a code or link, which is disclosed on every page.
